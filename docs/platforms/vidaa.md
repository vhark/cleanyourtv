# VIDAA (`vidaa`)

**Coverage:** offline plan and manual settings only; no network inspector, package manager, remote pairing or launcher integration in this fork. No hardware validation. Hisense and Toshiba also sell other OS families: confirm VIDAA in the actual TV's About/System Information and record exact model, software and region privately.

## Practical cleanup

1. Record app order and original notification/privacy values. Keep required TV/input, streaming and voice functions on an owner-approved checklist.
2. Start with moving favorites in Home's app management controls rather than deleting anything. For the **Hisense 40A4GV manual's layout**, open **App Store > My Apps**, select an unwanted installed app, choose **Remove**, then **OK**. Other VIDAA versions use a long-press app menu; follow your exact manual if this differs. Do not assume preinstalled apps are removable or that a missing app can be installed from an APK.
3. That manual also documents **Home > Notifications > Settings** with categories including Advertising, New Arrivals, Warnings and Legal Statements, and System Message. Turn off only unwanted promotional categories actually offered; retain useful system warnings. A notification preference does not remove all advertising.
4. Review optional viewing-recognition/Enhanced Viewing and HbbTV controls in your model's privacy/settings pages if offered. VIDAA's Data Act notice says these optional features can be toggled off; no universal menu path or effect on third-party app tracking is established. Leave HbbTV on if the owner relies on its interactive broadcast services.
5. Read **Settings > Support > Disclaimer and Privacy** where present. Review optional consents individually; withdrawing required service terms can disable services. Do not blindly accept every agreement just to tidy Home.

## Permission boundary and closed-platform limits

Manual cleanup requires no developer mode or network access. VIDAA's official mobile app is a separate option: the vendor says it needs the same network and accepted license/privacy terms, and recommends checking **Support > Mobile App** for the correct app version. That pairing is not performed or implemented here. Do not forward control ports or share pairing data.

VIDAA's store is not Android's Play Store. No arbitrary-app sideload, Android launcher, root or system-app debloat route is promised. Manufacturer support, not the OS badge alone, determines the available controls. If your model offers no Remove or optional viewing toggle, record that limitation rather than substituting ADB or a service menu.

## Undo and validation

Restore recorded notification/privacy values and app positions. Reinstall a removed app only if still offered by that regional store; its data/sign-in may not return. Do not use factory reset as routine undo. Test physical Home, required playback, inputs/tuner, volume/CEC, voice if retained, standby and restart. Verify broadcast interactive features if HbbTV changed.
