# VIZIO SmartCast / VIZIO Home (`vizio-smartcast`)

**Coverage:** offline plan and manual settings; no VIZIO inspector, token pairing, app installer, debloat or launcher replacement in this fork. No hardware validation. Confirm the exact model, current software and platform in the TV's System Information/user manual. Older VIA/VIA Plus app instructions must not be assumed to apply to SmartCast.

## Scoped manual cleanup

1. Privately record software version, Home app selections and current Viewing Data/privacy values. Keep the owner-approved input, tuner, streaming, casting and voice features available.
2. On the current documented SmartCast interface, press **Menu/Gear > All Settings > Privacy and Legal > Viewing Data** and switch it **Off** if the owner declines ACR collection. VIZIO's support article scopes this control to the selected TV. Older VIA Plus uses **System > Reset & Admin > Viewing Data**, which is not the default path for every SmartCast TV.
3. Read the separate activity/service privacy choices. VIZIO's FAQ explicitly distinguishes **Viewing Data** from **Activity Data** collected through SmartCast products. Turning off ACR is not a blanket opt-out from activity collection or third-party services. Do not factory-reset simply to follow an old privacy FAQ's account/setup path.
4. For Home app clutter, VIZIO's current setup help directs users to **VIZIO Home > Left Arrow > Apps > Home Screen Apps** to change favorites. Use those controls only if present; removing a favorite is not system-app deletion. Built-in/cloud app availability is vendor-controlled: no arbitrary APK or app-store installation promise.
5. Select the wanted HDMI input using the normal Input menu when using an external streamer. No universal power-on-to-input switch was verified from the available VIZIO support extraction; consult the exact model manual rather than promising Home bypass or remote macros.

## Permission boundary and limits

Normal settings need only owner permission and the physical remote. Official VIZIO mobile control is separate and may require account/pairing approval; no pairing or unofficial local API is implemented here. A local-control token is not root or permission to remove system components. Do not enable service menus, block updates or use Android tools.

## Undo and validation

Restore app favorites/order and original privacy choices through the same menus. Re-enabling a collection setting does not recreate deleted history; opt-out/data deletion can be irreversible even though the switch itself is reversible. No firmware or full app-data backup is provided.

Check physical Home/Back, selected streaming playback, HDMI switching, tuner/WatchFree behavior if used, casting/AirPlay if retained, volume/CEC, standby and restart. Verify the Viewing Data value on the actual screen; do not infer stopped network traffic from a toggle or claim all ads disappeared.
