# Panasonic My Home Screen (`panasonic-my-home-screen`)

**Coverage:** offline plan and manual Home editing only. No device inspection, package debloat, remote API or replacement launcher is implemented; no fork hardware validation. Panasonic also sells Android/Google TV and Fire TV models. Confirm the actual OS and exact model/software in the TV's About/eHELP before using this guide.

## Reduce Home clutter

1. Record original shortcut positions and any privacy/startup values privately. Use your model's eHELP **Using Home > Home > Option menu**, rather than assuming a newer Panasonic TV uses this system.
2. On Home, highlight an unwanted shortcut and press **OPTION > Unpin from HOME**. This removes the shortcut, **not** the underlying app or input.
3. Use **OPTION > Move** to put required shortcuts first. For the GZ1000 manual's layout, add a useful one through **Home > Devices / Apps / Live TV > select item > OPTION > Pin to HOME**, then select its position.
4. On a compatible remote/model, **Apps > selected app > OPTION > Set as My App** assigns a favorite to MY APP. The option is model-dependent; don't confuse it with reassigning Home.
5. The GZ1000 eHELP also documents an app **OPTION > Uninstall** command. It explicitly cannot uninstall some preinstalled apps. Only consider deleting a user-installed, recoverable app after accepting possible data loss. Leave unavailable/protected choices alone.
6. Read the exact model's terms/privacy options and disable optional personalization only if actually documented on that set. A single cross-version ad/ACR switch was not verified; don't fabricate one or copy Android package names.

## Permissions and limitations

These steps need owner consent and the physical remote, not developer mode or network access. Store installation/reinstallation can need network access and service-specific consent. Older app providers may discontinue services; unpinning is safer than assuming an app can be downloaded again. This closed platform has no supported Android package or APK route here. No root, firmware flashing, Home-button takeover or automatic remote sequences are offered.

## Undo and validation

Re-pin shortcuts through the same item menus and restore their positions; restore any recorded MY APP assignment. Do not use a reset of all Home/settings as routine undo. App deletion is not fully reversible if the service/store app is gone or its local data was erased.

Test physical Home and MY APP if changed, tuner, HDMI switching, chosen playback, volume/CEC, standby and restart. Confirm that an unpinned app remains accessible in Apps when expected. Home editing does not prove background-service removal or improved speed.
